HIGH-INTENT PAGE PRODUCTION

把值得做的 Query，
变成可以审核的页面。

聚类与页面决策 → 人工选题 → Brief 与文案 → 可视化预览与 QA → 内容交付。每批 1–5 页，保留两个人工审核点。

填写资料后，先测试 DeepSeek 连接。

连接 DeepSeek

使用 deepseek-flash。Key 只随当前请求发送，不写入项目、浏览器存储或导出文件。

01 / INPUT

本批页面的资料

支持文本、Markdown 和 CSV。可直接导入 Keyword Research Agent 导出的 Query Bank。产品事实与 CTA 地址请写清楚。

可从 Keyword Research Agent ↗ 下载人工批准的 CSV，再上传至下方 Query Bank。

每批最多 300 个 Query · 修改资料后需重新分析

02 / HUMAN GATE 1

哪些方向值得做页面？

查看已有页面覆盖与相互竞争风险，选择 1–5 组。P0 / P1 / P2 是建议；最终选题由你决定。

03 / PRODUCE & REVIEW

页面工作区

逐页生成，失败可单独重试。预览采用通用响应式模板，供审核文案和结构；品牌组件集成在目标仓库完成。

04 / HUMAN GATE 2

审核内容，交接实施

只有所有页面生成完毕且基础 QA 无 Fail，才能批准内容交付。工程检查与最终上线独立记录为 Not run。

项目只在当前浏览器页面内处理，不在服务器持久保存。刷新或关闭前请「保存项目」；项目含业务资料，请自行妥善保管。
